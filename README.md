# rodmwangi.github.io

Personal portfolio site for Rod Parsley Mwangi.

Policy research, gender and inclusion, governance, and 2.6 acres in Kajiado.

## About

This is a static HTML/CSS/JS site designed for GitHub Pages. No build tools, no frameworks, no dependencies. Just files a browser can read.

## Structure

- `index.html` - Main portfolio page
- `writing.html` - Writing section with JSON-driven content
- `writings/` - Markdown writing pieces + metadata JSON
- `images/` - Optimized photos
- `GUIDE.md` - Detailed guide for maintaining and updating the site

## Updating

See [GUIDE.md](GUIDE.md) for detailed instructions on updating content, adding projects, publishing writing pieces, and more.
